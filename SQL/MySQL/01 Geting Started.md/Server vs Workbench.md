* **MySQL Community Server** → This is the actual/Local **database server** (where data is stored).
* **MySQL Workbench** → This is a **GUI tool** to interact with the server (querying, designing DBs, etc). we can deal with Local or remote server using this.

install **both** unless you're fine using CLI or some other DB tool.

if we install only server we can have local DB but need to access with only CLI.  
if we install only workbench we can only access remote DBs cause on local the server is absence.  
if we install both, we have local DB & GUI, we can access out local SB with GUI. & with remote of course.
